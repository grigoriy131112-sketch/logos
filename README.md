# Λ Логос

**Логос** — блог, чтобы делиться мыслями и публикациями.
Название взято с самого начала идеи: *логос* — это одновременно «слово»,
«мысль» и «смысл».

## Возможности

- Публикация текстов с разметкой **Markdown**;
- лента публикаций с кратким описанием и датой по-русски;
- темы (теги) с переходом по клику и облаком тем в боковой панели;
- поиск по заголовку, тексту и описанию;
- комментарии — отклики читателей;
- страница «О блоге», страница 404;
- JSON API: `GET /api/posts` (поддерживает `?tag=` и `?q=`).

## Стек

Python 3, Flask 3, SQLite (стандартная библиотека), Markdown, чистый CSS/JS.
Никаких сборщиков и внешних сервисов — сайт запускается одной командой.

## Запуск

```bash
pip install -r requirements.txt
python seed.py      # необязательно: три стартовые публикации
python run.py       # http://localhost:12000
```

Порт задаётся переменной окружения `PORT` (по умолчанию 12000).

## Проверка

```bash
python test_app.py
```

Скрипт прогоняет 9 сценариев: главная, создание публикации, валидация,
API, комментарий, поиск, фильтр по тегу, «О блоге», 404.

## Структура

```
app/
  __init__.py     фабрика приложения, фильтры шаблонов, обработчик 404
  db.py           схема SQLite и функции работы с данными
  routes.py       маршруты блога
  templates/      base, index, post, new_post, about, 404
  static/css/     style.css — редакционный дизайн
  static/js/      app.js — автовысота поля ввода, скрытие сообщений
run.py            точка входа
seed.py           стартовые публикации
test_app.py       проверки маршрутов
instance/         файл базы данных logos.sqlite3 (не в git)
```

## Маршруты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/` | лента, фильтр `?tag=`, поиск `?q=` |
| GET | `/post/<id>` | публикация и её отклики |
| GET/POST | `/new` | создание публикации |
| POST | `/post/<id>/comment` | добавить отклик |
| GET | `/about` | о блоге |
| GET | `/api/posts` | список публикаций в JSON |
